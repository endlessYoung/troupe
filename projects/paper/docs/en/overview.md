# Paper

A small Markdown tool. It exists because Markor's interface is too raw.

MVP is frozen: Write + Manage. No sync, no collaboration, no AI features. Cross-platform choice is option C — Android first, with room in the architecture for other clients later.

The planning pack holds 35 backlog items (28 of them P0), ADR-001 on the module split, a 40-case test plan, and two review rounds whose 39 comments are closed.
