# Warroom

The floor where the troupe is visible. It is a Vite + TypeScript page with a three.js base, driven only by `window.TeamEvents`.

Swap `app/team.config.json` to point the same floor at another team. UI strings live in `app/src/i18n`. The simulated director is the default source; `RealtimeAdapter` is the marked seam for a live agent stream.
